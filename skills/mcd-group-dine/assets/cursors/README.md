# 一体式薯条包装光标

这组原创 SVG 把金色薯条与红色包装融入同一个箭头轮廓；包装内嵌双拱门式 M 灵感标记，强化快餐品牌联想，没有第二支系统箭头或鼠标跟随层。标记为自行绘制，并非导入的官方商标资源。

| 文件 | 用途 | 画布 | CSS 热点 |
| --- | --- | --- | --- |
| `fries-arrow.svg` | 默认红色包装 | 32 × 34 | 2, 2 |
| `fries-arrow-action.svg` | 可点击的金色包装 | 32 × 34 | 2, 2 |

两个状态保留完全相同的轮廓和尖端，不会在进入按钮时改变指针的实际位置。外缘用浅色描边，内部用深色轮廓，保证在奶油色和深色区域都能看清。小尺寸下只保留三根薯条与双拱门式 M：默认红袋上为金色，点击状态金袋上为深红色。

`scripts/cursor.mjs` 的 `brandCursorCss()` 负责读取并内嵌文件，生成的单文件账单不需要额外网络请求。应放在页面现有样式之后，并移除先前重复的自定义光标定义。

- 只有 `(hover:hover) and (pointer:fine)` 成立时启用；触屏不启用。
- 链接、按钮、原生展开按钮使用金色状态，系统回退是 `pointer`；默认回退为 `auto`。
- 输入区与可编辑文本保留 `text`。禁用按钮使用 `not-allowed`，忙碌操作使用 `progress`。
- 强制颜色模式恢复系统光标，打印使用 `auto`；光标没有跟随动画和常驻动画帧循环。
- 本组资源遵循项目 MIT 许可。

本地验证共 44 项，覆盖 SVG 尺寸、浏览器解析后的热点、默认/点击/输入/禁用/忙碌状态、双拱门颜色与三根薯条一致性、强制颜色模式、粗指针禁用，以及 18 格测试网格两侧的 36 次边界命中。无头截图不包含操作系统实际指针；放大检视图展示的是相同 SVG 源文件，不能代替实体鼠标、系统缩放或其他浏览器的人工检验。
