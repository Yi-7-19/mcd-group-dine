# 食物视觉素材

本目录 4 张图片由内置图像模型为本项目原创生成，并导出为 WebP：

- hero.webp：汉堡、薯条、冰饮聚餐氛围主视觉，1200×800。
- chicken.webp：烤鸡腿堡风格示意，640×640。
- double-beef.webp：双层牛肉堡风格示意，640×640。
- fish.webp：鱼排堡风格示意，640×640。

统一使用奶油色背景与暖色棚拍光线。图片不含官方 Logo 或官方商品包装，不是麦当劳官方产品摄影，也不保证实际商品外观与示意一致。页面已标注 AI 示意；商品价格和归属来自真实输入数据。

没有明确餐品类型的条目不强行使用某种汉堡照片，使用简洁的餐品图标展示真实名称、金额和归属。

文件尺寸、字节数和 SHA-256 见 manifest.json。生成的原图保留在本地工作素材中；运行 Skill 只依赖本目录的 WebP 文件，不需要网络图片服务。
