# 演示脚本

这份脚本是讲解提纲，不是 WorkBuddy 原始对话或真实调用证明。演示数据与真实核价截图须清楚区分。

## 30 秒介绍

三个人一起点餐，麻烦的不只是吃什么，还有每个人预算不一样、共享小食怎么算、优惠和配送费怎么分。麦麦同桌先用麦当劳 MCP 查真实门店、菜单和官方应付，再按餐品归属和共享份额分账。每个人都能看到自己的餐品、优惠、费用和预算状态，而且加起来必须与官方总额一分不差。

## 建议演示顺序

1. 输入三人各自预算、餐品偏好、公共地点和到店取餐方式。
2. 展示 WorkBuddy 真实查询门店、菜单及 calculate-price 的调用结果。
3. 打开 live-report.html，说明核价时间与门店，指出本次没有适用优惠券时不强行计算优惠。
4. 打开模拟的 demo-report.html，演示共享小食、整单优惠和附加费用的分摊；明确这是模拟数据。
5. 展示 A、B、C 的应付之和等于整单应付；把某人预算降低，演示个人超预算提示。

本次只完成试算和分账。现场演示不要点击真实下单、领券、兑换或付款，也不要展示 Token、券码或私人地址。
